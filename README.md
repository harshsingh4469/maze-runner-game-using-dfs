
# 🧩 Maze Runner Game using DFS (Python)

This project demonstrates a **Maze Runner Game** implemented using the **Depth First Search (DFS)** algorithm in Python.

## 🔍 Problem Statement
Given a 2D maze with:
- `S` → Start
- `E` → End
- `1` → Wall
- `0` → Open Path

The goal is to find a valid path from **Start to End** using DFS.

## 🧠 Algorithm Used
- **Depth First Search (DFS)**
- Uses recursion and backtracking
- Explores one path fully before trying alternatives

## 🗺️ Symbols Used
| Symbol | Meaning |
|------|--------|
| S | Start |
| E | End |
| 1 | Wall |
| 0 | Path |
| * | Solution Path |
